# LuBomben Tap

## How do I install these casks?

`brew install lubomben/tap/<cask>`

Or `brew tap lubomben/tap` and then `brew install <cask>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lubomben/tap"
brew "<cask>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
